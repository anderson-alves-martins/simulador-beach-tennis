# Política de segurança

## Reportar uma vulnerabilidade

Não publique credenciais, tokens ou detalhes exploráveis em issues públicas.

Use a opção **Report a vulnerability** na aba **Security** do GitHub para enviar um relato privado, quando disponível. Se essa opção não estiver habilitada, contate o responsável pelo repositório por um canal privado antes de divulgar detalhes.

Inclua:
- descrição e impacto provável;
- passos mínimos para reproduzir;
- commit ou versão afetada;
- sugestão de correção, se houver.

Não inclua credenciais reais no relato. Se uma credencial tiver sido exposta, revogue-a ou rotacione-a imediatamente.
